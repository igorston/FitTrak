# Contexto do Projeto (FitTrak)

Este documento centraliza as informações sobre o estado atual, a arquitetura e as decisões tomadas ao longo do desenvolvimento do projeto FitTrak.

## Objetivo
Criar uma interface simples, elegante e altamente responsiva para acompanhamento de um plano de treino específico, sem a necessidade de banco de dados ou infraestrutura complexa (Serverless/Static).

## Mudanças Recentes
- **Hospedagem:** O projeto foi ajustado para rodar no GitHub Pages, tendo seu arquivo principal renomeado para `index.html`.
- **Estrutura e Qualidade:** Adição de documentação (`README.md`, `context.md`, `changelog.md`) e testes automatizados para garantir a qualidade de entrega conforme a política de desenvolvimento estabelecida.

## Próximos Passos
- Refinar os testes e implementar testes de interface em navegadores caso necessário.
- Possível integração de service workers (PWA) para funcionamento offline completo.
