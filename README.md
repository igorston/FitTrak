# FitTrak (Treino ABC Pro)

Este projeto é uma aplicação de página única (Single Page Application - SPA) em HTML/JS/CSS projetada para exibir e gerenciar um treino de hipertrofia focado em atletas avançados (Treino ABC). 

## Tecnologias
- HTML5
- CSS (TailwindCSS via CDN)
- JavaScript Vanilla

## Funcionalidades
- Interface moderna adaptada para mobile (Dark mode nativo com tema Slate).
- Gerenciamento de 3 treinos (A - Push, B - Pull, C - Legs/Core).
- Temporizador embutido para intervalos de descanso, com feedback visual.
- Marcação de séries concluídas que são salvas via `sessionStorage`.
- Modal de técnicas avançadas.

## Hospedagem e Configuração
A aplicação foi configurada para funcionar perfeitamente com o GitHub Pages. O arquivo de entrada principal é `index.html`. Nenhuma build adicional é necessária.
